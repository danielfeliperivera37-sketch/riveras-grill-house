# Rivera's Grill House
Sistema web de pedidos en línea para un restaurante de comidas rápidas.

## Tecnologías
Python, Flask, SQLite, HTML, CSS y JavaScript.

## Funciones
- Menú por categorías y carrito de compras
- Registro y confirmación del pedido
- Consulta del estado del pedido
- Panel de administración protegido con contraseña

## Ejecutar

```
pip install flask
python app.py
```

Variables opcionales: BURGER_ADMIN_PASSWORD y BURGER_SECRET_KEY.
